# The Odds

An almanac of improbabilities — a single-file, static, dependency-free site published on GitHub Pages.

## Contents
- § 01 The Board — eight everyday odds, drawn to scale
- § 02 The Simulator — the law of large numbers, run live in your browser
- § 03 The Scale — ten events on one logarithmic axis

## Publish
```bash
bash deploy.sh
```

## Notes
No build step, no framework, no trackers. Edit `index.html`, commit, push.
